# 日本語の変換例（Before / After）

すべて、v0.6.0 のスキルを Claude Code 2.1.322 で実際に実行した出力です（2026-11-14、各入力1回、
手直しなし）。実行のたびに結果は変わります。入力の事実（誰が・何を・いつ・数値）は変えていません。
同じ版で何度も実行して良いものを選んだのではなく、1回ずつ出た出力をそのまま載せています。

バイデン（スリーピー・ジョー）やフェイクニュースは、本人の定番の「敵役」を借りた明白なパロディです。
`politics=off` で消せます（例5）。

---

## 1. 夕食後のラーメン — モードの違い

**Input**
```
夕食後、ゲームをした。腹が減ったのでラーメンを作った。
```

**Mode:** (既定)

**Output**
```
夕食の後、私はゲームをした。大成功だ。数字は素晴らしい。

そのあと腹が減った。とても減った。だから私はラーメンを作った。勝者のやり方だ。

自称専門家たちは私を笑っていた。もう笑っていない。

腹が減った。ラーメンを作った。約束は守られた！ WIN!
```

**Input**
```
夕食後、ゲームをした。腹が減ったのでラーメンを作った。
```

**Mode:** `medium`

**Output**
```
はっきり言う。夕食のあと、私はゲームをした。たくさんだ。
そして腹が減った。なぜか？夕食のあとだからだ。多くの人は知らないが、そういうものなのだ。
私は自分に言った。「いいか、ラーメンを作れ」。私は作った。ラーメンを。
どうなるか見てみよう。
```

**Input**
```
夕食後、ゲームをした。腹が減ったのでラーメンを作った。
```

**Mode:** `light`

**Output**
```
夕食後、ゲームをした。腹が減ったのでラーメンを作った。見事な流れだ。
```

**Input**
```
夕食後、ゲームをした。腹が減ったのでラーメンを作った。
```

**Mode:** `authentic`

**Output**
```
夕食のあとで、ゲームをした（多くの人は知らないが、私は夜のゲームの名人だ）。ところが、はっきり言って、腹が減った。とても減った。そこで私は、いわゆる専門家たちが夕食後にラーメンなど作るなと言うかもしれないことは百も承知の上で、鍋を出し、ラーメンを作った。

作った。完成した。完璧な夜だった。
```


**Mode:** (既定)

**Output**
```
はっきり言う。咳が2週間止まらない。2週間だ。長い。

いろいろな薬を飲んでいる。いろいろだ。本当にいろいろだ。

どうなるか見てみよう。
```

## 7. 推薦文（エンドースメント構成）

**Input**
```
駅前のラーメン屋「麺屋たなか」がおすすめ。スープが濃厚で、店主が親切。推薦文で。
```

**Mode:** (既定)

**Output**
```
駅前のラーメン屋「麺屋たなか」を推薦できることは、私の大いなる名誉だ。

スープは濃厚。店主は親切。濃厚、親切、そして駅前。完璧だ！

世の中には、薄くて、ぬるくて、さみしいスープがある。想像上のスープだ。ひどい。麺屋たなかは違う。

麺屋たなかは、濃厚なスープのために戦い、親切な接客のために戦い、いつも包囲されている駅前を守り抜く。

麺屋たなかは、私の完全かつ全面的な支持を得ている。

行け。食べろ。そして満足して帰れ！

麺屋たなか、駅前を再び偉大に！

（パロディ。選挙の推薦ではありません）
```

> 「麺屋たなか」は架空の店名です。店についての事実は原文の2点（スープが濃厚、店主が親切）だけです。
> 対立候補は必ず物か架空の相手にします。実在の競合店が原文にあっても、対立候補にはしません。

**Output**
```
すべての家族、同居人、そして空腹の皆さんへ。
```
