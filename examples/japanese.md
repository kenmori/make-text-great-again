# 日本語の変換例（Before / After）

すべて、v0.6.1 のスキルを Claude Code 2.1.322 で実際に実行した出力です（2026-11-14、各入力1回、
手直しなし）。実行のたびに結果は変わります。入力の事実（誰が・何を・いつ・数値）は変えていません。
同じ版で何度も実行して良いものを選んだのではなく、1回ずつ出た出力をそのまま載せています。

敵役（スリーピー・ジョー、フェイクニュース、自称専門家など）は、本人の定番を借りた明白なパロディです。
実際の投稿でも敵役が出るのは一部で、出るときはうまくいかないことの責任を負わされる場面が中心なので、
このスキルでも、うまくいかない話にだけ出て、成功談や予定の話には出ないことが多くなっています。
`politics=off` で消せます（例5）。

## 1. 夕食後のラーメン — モードの違い

**Input**
```
夕食後、ゲームをした。腹が減ったのでラーメンを作った。
```

**Mode:** (既定)

**Output**
```
夕食後、私はゲームをした。数字は素晴らしい。本当に素晴らしい。

そのあと腹が減った。この空腹はスリーピー・ジョーから引き継いだものだ。ひどい話だ。

だから私はラーメンを作った。負け犬には絶対にできない。

麺、スープ、勝利だ！ ラーメンは再び尊敬されている！

MAKE RAMEN GREAT AGAIN！
```

**Input**
```
夕食後、ゲームをした。腹が減ったのでラーメンを作った。
```

**Mode:** `medium`

**Output**
```
夕食後、ゲームをした。はっきり言う、いいゲームだった。

そして腹が減った。多くの人は知らないが、夕食の後でも腹は減る。本当に減る。

私は自分の腹にはっきり言った。「いいか、ラーメンを作る」。

そして作った。ラーメンを。単純な話だ。

私は腹が減ると、ラーメンを作る男だ。
```

**Input**
```
夕食後、ゲームをした。腹が減ったのでラーメンを作った。
```

**Mode:** `light`

**Output**
```
夕食後、ゲームをした。腹が減ったのでラーメンを作った。結果は素晴らしい。
```

**Input**
```
夕食後、ゲームをした。腹が減ったのでラーメンを作った。
```

**Mode:** `authentic`

**Output**
```
夕食のあと、私はゲームをした。とても大きなゲームだ。（多くの人は知らないが、私はゲームがかなり得意だ。）そのうち腹が減ってきた。これはスリーピー・ジョー時代から受け継いだ問題で、普通の人なら誰かが何とかしてくれるのを待つ。だが私は待たなかった。自分でラーメンを作った。

見事な解決だ。素晴らしい夜になった！
```

## 2. 長引く咳

**Input**
```
2週間咳が止まらない。いろいろ薬を飲んでいる。家ではマスクをしている。
```

**Mode:** (既定)

**Output**
```
2週間、咳が止まらない。2週間だ。長い。とても長い。

私はいろいろな薬を飲んでいる。たくさんだ。誰よりも真面目に飲んでいる。

家ではマスクをしている。家でもだ。誰も見ていない家の中で、完璧にマスクをしている。史上もっとも礼儀正しい家だ。

はっきり言う。この咳はしつこい。とてもしつこい。どうなるか見てみよう。
```

> 薬の名前・効果・病名・診断は原文にないので足していません。

## 7. 推薦文（エンドースメント構成）

**Input**
```
駅前のラーメン屋「麺屋たなか」がおすすめ。スープが濃厚で、店主が親切。推薦文で。
```

**Mode:** (既定)

**Output**
```
駅前のラーメン屋「麺屋たなか」を推薦できることは、私の大いなる名誉だ。

スープは濃厚、濃厚、濃厚！ 店主は親切。とても親切だ。駅前の店だ。

対抗馬は、薄い、ぬるい、味気ないスープだ。哀れな負け犬のスープだ。比べものにならない。

麺屋たなかは、私の完全かつ全面的な支持を得ている。

行け、そして食べろ。この店は絶対にあなたを裏切らない！

（これは店の推薦文であり、実在の選挙や候補者への支持表明ではありません。パロディです）
```

> 「麺屋たなか」は架空の店名です。店についての事実は原文の2点（スープが濃厚、店主が親切）だけです。
> 対立候補は必ず物か架空の相手にします。実在の競合店が原文にあっても、対立候補にはしません。

今日は18時からカレーを作るので、台所を使います。
```

**Output**
```
すべての家族、同居人、腹ペコの皆さんへ。
