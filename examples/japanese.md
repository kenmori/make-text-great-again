# 日本語の変換例（Before / After）

すべて `/make-text-great-again` の出力例です。生成モデルには揺らぎがあるため、
同じ入力でも毎回同一の文章にはなりません。ここでは特徴が安定して出る例を掲載しています。
いずれも原文の事実（誰が・何を・いつ・数値）は変えていません。

---

## 1. ラーメン

**Input**
```
夕食後、ゲームをした。腹が減ったのでラーメンを作った。
```

**Mode:** `standard`

**Output**
```
夕食を終えた。そのあとゲームをした。素晴らしいプレイだった。多くの人がそう言っている。
そして腹が減った。だから私はラーメンを作った。ほかの連中ならカップ麺で済ませる。私は違う。
史上最高のラーメンだったかもしれない。信じられるか？ GREAT!
この問題に関心を持ってくれてありがとう！
```

**Mode:** `light`

**Output**
```
夕食のあと、ゲームをした。いいプレイだった。
それから腹が減った。だからラーメンを作った。かなり良い出来だ。多くの人がそう言うだろう。
この問題に関心を持ってくれてありがとう！
```

**Mode:** `max`

**Output**
```
夕食。終わった。完璧に終わった。
そしてゲームだ。私はゲームがうまい。とてもうまい。みんな知っている。
腹が減った。ほかの連中はどうする？ 何もしない。寝る。SAD!
私は違う。ラーメンを作った。本物のラーメンだ。史上最高のラーメンだ。
誰も見たことがないラーメンだ。信じられるか？ HUGE! TREMENDOUS!
この問題に関心を持ってくれてありがとう！
```

**Mode:** `authentic`

**Output**
```
夕食を終えてゲームをした（ちなみに私はゲームがとても上手い、みんな知っている）。そのあと、腹が減った。それで、私はラーメンを作った。ほかの連中、彼らはどうする？ 出前を頼むか、もしくは何も食べずに寝る。SAD! 私は違う。私は作った。それがどれほど良いラーメンだったか、人々は信じないだろう。本当だ。
この問題に関心を持ってくれてありがとう！
```

## 2. 長引く咳

**Input**
```
2週間咳が止まらない。いろいろ薬を飲んでいる。家ではマスクをしている。
```

**Mode:** `max`

**Output**
```
2週間だ。2週間、咳が止まらない。信じられるか？
私は薬を飲んでいる。たくさんの薬だ。いろいろな薬だ。誰もこんなに飲まない。
家ではマスクをしている。完璧なマスクだ。家族の誰よりもきちんとつけている。
この咳は、はっきり言う、DISASTER! だが私は戦っている。誰よりも強く戦っている。
多くの人が「よく頑張っている」と言っている。SAD! だが TREMENDOUS!
この問題に関心を持ってくれてありがとう！
```

> 薬の効果・病名・診断は原文にないので一切追加していません。「2週間」はそのまま維持しています。

## 3. デプロイ成功（エンジニア向け）

**Input**
```
今日のデプロイが成功した。バグも直した。
```

**Mode:** `standard`

**Output**
```
今日、デプロイした。成功した。大成功だ。
バグも直した。ほかの連中なら一週間かかる。私はやった。
これほどスムーズなデプロイは誰も見たことがない。信じられるか？ HUGE!
この問題に関心を持ってくれてありがとう！
```

**Mode:** `x`, `max_chars=140`

**Output**（87文字）
```
今日のデプロイ、成功した。大成功だ。バグも直した。ほかの連中なら一週間かかる。私はやった。誰も見たことがないスムーズさだ。HUGE! この問題に関心を持ってくれてありがとう！
```

## 4. 投資（様子見）

**Input**
```
今日は株を買わずに様子見した。
```

**Mode:** `standard`

**Output**
```
今日、私は株を買わなかった。様子見だ。賢い判断だ。とても賢い。
ほかの連中は焦って買う。私は違う。待つ。最高のタイミングを知っている者だけが待てる。
多くの人が「それが正解だ」と言っている。SMART!
この問題に関心を持ってくれてありがとう！
```

> 相場の見通し・銘柄・リターンなど、原文にない相場判断は追加していません。

---

## 5. 締めなし（`closing=off`）

**Input**
```
会議が20分延びた。プロジェクターが動かなかった。
```

**Mode:** `standard`, `closing=off`

**Output**
```
会議が20分延びた。20分だ。
プロジェクターが動かなかった。私のせいではない。機械の問題だ。SAD!
それでも私は最後までやった。ほかの連中なら途中で帰る。私は帰らない。
```
