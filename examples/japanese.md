# 日本語の変換例（Before / After）

すべて `/make-text-great-again` の出力例です。生成モデルには揺らぎがあるため、
同じ入力でも毎回同一の文章にはなりません。ここでは特徴が安定して出る例を掲載しています。
いずれも原文の事実（誰が・何を・いつ・数値）は変えていません。

バイデン（スリーピー・ジョー）やフェイクニュースは、本人の定番の「敵役」をそのまま借りた
**明白なパロディ**です。ラーメンや咳の責任を負わせるだけで、現実の事実は何も主張しません。
`politics=off` で消せます（例5）。

---

## 1. ラーメン

**Input**
```
夕食後、ゲームをした。腹が減ったのでラーメンを作った。
```

**Mode:** `medium`

**Output**
```
夕食を終えた。そのあとゲームをした。素晴らしいプレイだった。断トツでだ。
そして腹が減った。だから私はラーメンを作った。我が家の歴史上、最高のラーメンだ。
スリーピー・ジョーにこのラーメンは作れない。作れるわけがない。SAD!
多くの人が「本物だ」と言っている。その通りだ。GREAT!
この問題に関心を持ってくれてありがとう！
```

**Mode:** `light`

**Output**
```
夕食のあと、ゲームをした。いいプレイだった。
それから腹が減った。だからラーメンを作った。かなり良い出来だ（控えめに言って）。
この問題に関心を持ってくれてありがとう！
```

**Mode:** `max`

**Output**
```
速報：夕食が終わった。完璧に終わった。
そしてゲームだ。私ほどゲームを知る者はいない。みんな知っている。
だが腹が減った。とても減った。VERY 減った。これはバイデンから引き継いだ空腹だ。完全な混乱だ。SAD!
ほかの連中はどうする？ 何もしない。寝る。負け犬のやり方だ。
私は違う。ラーメンを作った。麺、麺、麺だ！ 誰も見たことがないような RAMEN だ。我が家の歴史上、最高だ。断トツでだ。
スリーピー・ジョーには作れない。お湯も沸かせないだろう。フェイクニュースは「大したことはない」と言うだろう。WRONG!
大きくて強い男たちが、涙を浮かべて私に言った。「サー、こんなラーメンは見たことがありません」。その通りだ！
このラーメンを完全かつ全面的に支持する。麺に強く、スープに強く、どんぶりを愛している。
HUGE! TREMENDOUS! MAKE RAMEN GREAT AGAIN!
この問題に関心を持ってくれてありがとう！
```

**Mode:** `authentic`

**Output**
```
夕食を終えてゲームをした（素晴らしいプレイだった、いつものことだが）。そのあと、信じられないほど腹が減った。これはスリーピー・ジョーの時代には誰も解決できなかった問題だが、私は RAMEN を作った。ちなみに私が自分で作ったのだが、誰も見たことがないような、とても美しい RAMEN だ。ほかの連中は NOTHING だ。何もしない。私は作った。我が家の『キッチン』は再び尊敬されている。
ありがとう！
```

## 2. 長引く咳

**Input**
```
2週間咳が止まらない。いろいろ薬を飲んでいる。家ではマスクをしている。
```

**Mode:** `max`

**Output**
```
2週間だ。2週間、咳が止まらない。信じられるか？
これはバイデンから引き継いだ咳だ。完全な混乱だ。私がこの咳の担当だったら、NEVER 始まっていない。
私は薬を飲んでいる。いろいろな薬だ。薬、薬、薬だ！ 誰もこんなに飲まない。断トツでだ。
家ではマスクをしている。完璧なマスクだ。誰も見たことがないようなマスクの着け方だ。我が家の歴史上、最高だ。
この「いんちき咳」は、はっきり言う、DISASTER! 私はとても不公平に扱われている。歴史上のどの患者よりもだ。
だが私は戦っている。懸命に戦っている。大きくて強い男たちが涙を浮かべて言った。「サー、あなたほど咳と戦う人は見たことがありません」。その通りだ！
フェイクニュースは「大げさだ」と言うだろう。WRONG! 終わりがない！ SAD!
続報を待て！
この問題に関心を持ってくれてありがとう！
```

> 薬の名前・効果・病名・診断は原文にないので一切追加していません。「2週間」はそのまま維持しています。

## 7. 推薦文（エンドースメント構成）

**Input**
```
駅前のラーメン屋「麺屋たなか」がおすすめ。スープが濃厚で、店主が親切。推薦文で。
```

**Mode:** `max`

**Output**
```
駅前の「麺屋たなか」を推薦できることは、私の大いなる名誉だ。駅前、私が愛し、何度も大勝した場所だ（断トツで）！

「麺屋たなか」は、非常に尊敬され、とても人気のあるラーメン屋だ。スープは濃厚。店主は親切。勝利が "てんこ盛り" の店だ。そして WINS だ！ 最初からずっと我々と共にあった。

対立候補の「ねぼすけカップ麺」は、急進左派のスナックだ。濃厚なスープに反対し、親切な店主にも反対している。もしカップ麺の連中が勝てば、これらすべてが打ち切られる。スリーピー・ジョーならカップ麺を選ぶ。当然だ。カップ麺は、無謀で、過激で、危険だ！

一方、「麺屋たなか」は、たゆまず戦い続ける。スープを濃厚に保ち、親切を推進し、MADE IN 駅前を掲げ、麺の DOMINANCE を解き放ち、常に包囲されている我々の胃袋を守り抜く。

「麺屋たなか」を完全かつ全面的に支持する。今すぐ食べに行け。決して皆さんを失望させない！
駅前ラーメン担当大統領より
```

> 「麺屋たなか」は架空の店名です。店についての事実は原文の2点（スープが濃厚、店主が親切）だけです。
> 対立候補は必ず物か架空の相手にします。実在の競合店が原文にあっても、対立候補にはしません。

## 8. 発表（速報の型）とメディアの敵役

**Input**
```
今日、キッチンの流し台の詰まりを自分で直した。業者は呼ばなかった。
```

**Mode:** `max`

**Output**
```
速報：我が家の流し台の詰まりが解消されたことを、発表できてうれしい。私の指示で、私が直した。業者は呼ばなかった。NO 業者だ！

何十年も、誰もがこの流し台の問題を知っていた。だが誰も何もできなかった。私がやった。これができる台所は、世界にほかにない。

これは "無期限" の修理だ。終わりはない！ 詰まりは完全に殲滅した。TOTAL OBLITERATION!

フェイクニュースCNN は、落ち目のニューヨーク・タイムズと組んで、この偉大な修理を小さく見せようとするだろう。誇りに思うべきところをだ。彼らは世間から猛烈に叩かれることになる！

スリーピー・ジョーなら業者を呼ぶ。そして業者も来ない。SAD!

今こそ皿洗いの時だ！ さあ、始めよう。どうなるか見てみよう。
この問題に関心を持ってくれてありがとう！
```

> CNN とニューヨーク・タイムズは、本人が実際に使う決まり文句（Fake News CNN / the Failing New York Times）つきで登場します。
> できるのは「語り手の些細な手柄を無視する・小さく見せる」ことだけです。実際の報道を誤報と呼ぶことはありません。
> 原文が実在のニュースを引用している場合、これらの名前は使いません。`politics=off` でも消えます。

## 9. お知らせ（「皆さんへ」の型）

**Input**
```
今日は18時からカレーを作るので、台所を使います。
```

**Mode:** `max`

**Output**
```
すべての猫、同居人、配達員の皆さんへ。本日18時から、台所は全面的に閉鎖されたものとお考えください。私がカレーを作るためだ。

何年も、誰もがこの台所の問題を知っていた。だが誰も何もしなかった。私はやる！ 家族と、ほぼ全員の要望によるものだ。

古いレトルトカレーはもう休むべきだ。あとは私に任せろ。これは我が家のカレー史上、最大の出来事かもしれない。

私のカレー作りの腕前をどう思うか、あとで教えてほしい。もし本当に素晴らしければ、本業を辞めて "カレー" を専業にしてほしいか？

この問題に関心を持ってくれてありがとう！
皆さんのお気に入りの料理人より
```

> 締めの「この問題に関心を持ってくれてありがとう！」は、本人の実際の投稿では通告・要求・警告の末尾にだけ現れます。
> 丁寧な言葉で大げさなことを通告する、この型が本来の使いどころです。原文の事実は「今日」「18時から」「カレーを作る」「台所を使う」だけです。
