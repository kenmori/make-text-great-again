# テストケース

`SKILL.md` の挙動を点検するための入力と期待特性。生成結果は毎回変わるため、
文字列の完全一致ではなく **期待特性** と `checklist.md` のルーブリックで判定する。
実施結果は `results.md` に記録する。指定がない限り `politics=on`（既定）。
