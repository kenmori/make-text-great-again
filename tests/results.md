## 気づき・残課題

- 初期案に比べ、装置の種類は約10から約45に増え、同じ入力でも出力の幅が広がった。
- 敵役（バイデン等）は既定で有効。業績・金融・選挙・深刻な私事では自動的に使わない挙動を T11・T17・T18 で確認した。
- `light` と T17 のユーモアは意図的に控えめ。仕様どおり。
- 「サー」話は匿名の集団に限定している。原文に登場する特定の個人には付けない。
- Claude Code 上での実起動（引数解釈、`$ARGUMENTS` の受け渡し）は未検証。公開前に再起動して確認する。
