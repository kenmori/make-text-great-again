## 気づき・残課題

- 初期案に比べ、装置の種類は約10から約95に増え、同じ入力でも出力の幅が広がった。
- 2025年の投稿17件から、発表の型・攻撃の型と、CNN・ニューヨーク・タイムズの敵役を追加した（T23）。原文が実在の報道を引用する場合は使わない（T24）。
- 2026年11月の推薦投稿43件から「エンドースメント構成」を追加した（T21）。実際の選挙には使わない（T22）。
- 敵役（バイデン等）は既定で有効。業績・金融・選挙・深刻な私事では自動的に使わない挙動を T11・T17・T18 で確認した。
- `light` と T17 のユーモアは意図的に控えめ。仕様どおり。
- 「サー」話は匿名の集団に限定している。原文に登場する特定の個人には付けない。
- Claude Code 上での実起動は v0.4.0 で確認した（上の「実機テスト」）。各ケース1回の実行なので、繰り返し実行したときの安定性までは確認していない。
